# frontend-react-aggrid — 프런트엔드 구현 규칙

## 고정 기술
- React. 다른 프레임워크로 바꾸지 않는다.
- 표 컴포넌트는 AG Grid Community만 쓴다.
- 데스크톱 브라우저 기준이다. 정보 밀도와 마우스·키보드 효율을 우선한다.

## 필수 규칙
- **`ag-grid-enterprise`를 설치하지 않는다.** 필요해 보이는 기능이 Enterprise 전용인지 먼저 확인한다.
- **API는 상대경로:** `${APP_BASE_PATH}/api`로 호출한다(호스트 없는 상대경로, 하위 경로 배포). 주소와 경로 접두(`/api`, `/bi-wizard` 등)를 하드코딩하지 않는다. `APP_BASE_PATH`는 프런트에 넘기는 유일한 공개 설정이며 빌드·런타임 기준 경로(Vite `base` 등)에 쓴다.
- **DB와 Superset 직접 호출 금지:** 모든 데이터는 FastAPI를 거친다. 예외는 Embedded SDK가 만드는 Superset iframe뿐이며, `supersetDomain`은 `SUPERSET_APP_ROOT`를 포함한 주소로 구성한다.
- **Secret 금지:** 번들에 `.env` 값을 넣지 않는다. 필요한 공개 설정만 런타임에 받는다.

## AG Grid Community의 한계와 대응
| 필요한 기능 | Community 지원 | 대응 |
| --- | --- | --- |
| 여러 셀 범위 선택 | 없음 | 직접 구현하거나 단일 셀 편집으로 범위를 좁힌다 |
| 클립보드 붙여넣기 (여러 행) | 없음 | 아래 "붙여넣기 구현" 참조 |
| .xlsx 내보내기 | 없음 | 서버에서 생성하거나 CSV를 제공한다 |
| 행 그룹, 피벗 | 없음 (Enterprise) | 집계는 백엔드 뷰로 만든다 |

## 붙여넣기 구현 (엑셀에서 여러 행 복사)
1. 그리드 컨테이너에 `paste` 이벤트 리스너를 단다.
2. `clipboardData.getData('text/plain')`으로 텍스트를 받는다. 엑셀은 탭으로 열을, 줄바꿈으로 행을 구분한다.
3. 행과 열을 나누고, 빈 마지막 줄을 제거한다. 따옴표로 감싼 셀의 줄바꿈을 처리한다.
4. 선택된 셀을 기준으로 열 타입에 맞춰 값을 변환한다. 변환 실패 셀은 표시하고 전체를 막지 않는다.
5. 덮어쓰기 전에 대상 범위와 행 수를 사용자에게 확인받는다.
6. 저장은 백엔드 API로 한 번에 보낸다.

## 화면 규칙
- **입력 그리드:** 열 정의에 따라 열 타입별 편집기를 쓴다. 필수, 범위, 정규식, 유일성 검증 오류는 셀 위치와 함께 보여준다.
- **가져오기 마법사:** 업로드 → 시트·범위 선택(헤더 자동 탐지, 수정 가능) → 열 제안 확인(이름 변경, 제외, 타입 변경) → 생성. 단계마다 되돌아갈 수 있어야 한다.
- **수식 편집기:** 열 이름 자동 완성, 오류는 SQL 용어가 아니라 사용자 말로 표시한다.
- **Superset 화면:** Embedded SDK로 FastAPI가 발급한 guest token을 써서 붙인다.

## 테스트
- 해당 프로젝트에 정한 테스트 도구를 쓴다. 컴포넌트 테스트와 붙여넣기 파서의 단위 테스트를 포함한다.
- 응답 구조가 백엔드 계약과 맞는지 확인한다. 타입 정의를 계약에서 가져온다.

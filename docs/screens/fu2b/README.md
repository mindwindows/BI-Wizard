# FU-2b 화면 스크린샷 (S2 보관·복구, S4 읽기 전용 배너) — 초안

상태: **초안(촬영 전)**. backend 구현이 끝난 뒤 별도 요청이 있을 때 촬영한다. 아래 표의 PNG는 아직 없다. 촬영 스크립트 `capture/capture2b.cjs`도 실행한 적이 없다.

- 크기: 1920×1080 PNG(viewport, 스크롤하지 않은 첫 화면). 파일 이름 `fu2b-{화면}-{상태}.png`(`03b` 30-2).
- 데이터: 전부 합성 값만 쓴다. 신원은 개발용 인증 스텁(`AUTH_STUB_ENABLED=true`, `APP_ENV=local`)의 정의 담당자 계정이다.

## 촬영 방법 (예정)
`fu2a`와 같다(`docs/screens/fu2a/README.md`). 임시 env 파일은 `_workspace/qa/`에 만든 더미 값만 쓰고, playwright는 `PLAYWRIGHT_MODULE`·`CHROMIUM_PATH`로 저장소 밖 설치를 가리킨다. 시드는 정의 담당자 팀과 데이터셋 3개 이상(사용 중 2, 보관 1)을 만든다. `ids2b.json` 형식은 스크립트 머리말에 있다.
